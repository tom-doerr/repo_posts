# [marcpope/borgbackupserver](https://github.com/marcpope/borgbackupserver)

Borg Backup Server is a self-hosted web application for centrally managing BorgBackup across multiple Linux, Mac, and Windows endpoints. It uses a lightweight agent that polls the server over HTTPS, enabling backups from behind firewalls. The tool offers full encryption, real-time progress tracking, file-level restores, and database plugins for MySQL and PostgreSQL.
