# [dbish/DispatchMail](https://github.com/dbish/DispatchMail)

Dispatch Mail is an open source tool that runs locally to manage your email inbox. You configure custom prompts for filtering mail, generating drafts, and auto-labeling folders, while the system stores all data in a local SQLite database.
