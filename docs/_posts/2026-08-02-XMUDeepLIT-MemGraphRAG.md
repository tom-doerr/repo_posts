# [XMUDeepLIT/MemGraphRAG](https://github.com/XMUDeepLIT/MemGraphRAG)

MemGraphRAG is a memory-based multi-agent system for Graph Retrieval-Augmented Generation that organizes knowledge into schema, fact, and passage layers, enabling conflict-aware construction and memory-derived graphs.
