# [Superior-Trade/superior-skills](https://github.com/Superior-Trade/superior-skills)

Superior Skills is an open-source library of trading schemas for agents that enables natural language strategy authoring, backtesting, and deployment on Hyperliquid. The repository includes validated templates with backtest evidence, alongside reusable primitives for trade logic, regime filtering, and fee optimization.
