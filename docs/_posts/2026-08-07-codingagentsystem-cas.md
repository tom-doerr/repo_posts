# [codingagentsystem/cas](https://github.com/codingagentsystem/cas)

CAS creates a multi-agent coding factory for Claude Code. A supervisor agent breaks down work while worker agents execute tasks in parallel within isolated git worktrees. The system also includes a context server to provide agents with persistent memory and skills across sessions.
