# [floci-io/floci-ui](https://github.com/floci-io/floci-ui)

Manage your local multi-cloud environment using Floci UI, a unified web console for developers. It consolidates AWS, Azure, and GCP emulation into a single interface that renders real infrastructure state rather than mock data.
