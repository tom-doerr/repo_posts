# [emanuele-f/PCAPdroid](https://github.com/emanuele-f/PCAPdroid)

PCAPdroid analyzes mobile network traffic without root by simulating a local VPN, allowing you to export PCAP dumps, inspect HTTP requests, and decrypt TLS connections.
