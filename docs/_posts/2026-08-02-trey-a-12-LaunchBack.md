# [trey-a-12/LaunchBack](https://github.com/trey-a-12/LaunchBack)

LaunchBack is a free and open-source re-implementation of the classic macOS Launchpad written in Swift. It acts as a standalone grid application launcher independent of Spotlight and Launchpad dependencies. The project serves as a drop-in replacement for users seeking to retain the traditional app browsing interface separate from native macOS integrations.
