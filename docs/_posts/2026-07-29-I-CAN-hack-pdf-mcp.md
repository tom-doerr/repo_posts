# [I-CAN-hack/pdf-mcp](https://github.com/I-CAN-hack/pdf-mcp)

pdf-mcp turns PDF documents into structured text and images for LLMs. It uses PyMuPDF to extract text in JSON, Markdown, or HTML formats, and renders pages as configurable PNGs.
