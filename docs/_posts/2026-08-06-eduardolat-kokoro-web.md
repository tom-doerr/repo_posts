# [eduardolat/kokoro-web](https://github.com/eduardolat/kokoro-web)

Kokoro Web is an open-source text-to-speech tool powered by the 82 million parameter Kokoro-82M model. It runs directly in your browser with zero installation or can be self-hosted as a fully OpenAI API compatible voice generator.
