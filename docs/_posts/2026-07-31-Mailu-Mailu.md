# [Mailu/Mailu](https://github.com/Mailu/Mailu)

Mailu is a full-featured mail server available as a set of Docker images. It simplifies deploying IMAP, SMTP, and webmail services while handling configuration profiles for clients. The project includes security measures like enforced TLS and DMARC, plus integrated antispam filtering, all contained within open-source components.
