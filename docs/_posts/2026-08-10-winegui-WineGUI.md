# [winegui/WineGUI](https://github.com/winegui/WineGUI)

Manages Windows applications on Linux through a user-friendly graphical interface. Handles Wine configuration, downloads versions, sets up virtual desktops, and installs software like DirectX or DXVK with single clicks.
