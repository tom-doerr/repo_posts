# [toinbox/simplerelay](https://github.com/toinbox/simplerelay)

SimpleRelay is a self-hosted SMTP relay with a dashboard that routes outbound emails through multiple providers like Gmail or Sendgrid based on sender address. It consolidates SMTP configuration into a single interface, allowing users to manage multiple upstream accounts and monitor send stats in real time.
