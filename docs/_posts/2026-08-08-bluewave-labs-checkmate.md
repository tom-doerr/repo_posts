# [bluewave-labs/checkmate](https://github.com/bluewave-labs/checkmate)

Checkmate is an open source self-hosted tool for tracking server hardware, uptime, and response times in real time. It features a Capture agent to retrieve detailed metrics like CPU, RAM, and disk usage from remote devices. The system is designed to handle over 1000 active monitors without performance bottlenecks.
