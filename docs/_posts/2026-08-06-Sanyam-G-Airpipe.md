# [Sanyam-G/Airpipe](https://github.com/Sanyam-G/Airpipe)

AirPipe is a self-hosted tool that enables secure peer-to-peer file transfers using a simple passphrase. It streams files directly between devices while ensuring the relay never accesses your data, making it an easy way to share large files across networks.
