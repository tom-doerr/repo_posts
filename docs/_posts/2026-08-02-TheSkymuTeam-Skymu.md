# [TheSkymuTeam/Skymu](https://github.com/TheSkymuTeam/Skymu)

Skymu is an instant messenger that replicates the interface of classic Skype versions 4, 5, 6, and 7 while supporting networks like Matrix, Tox, and MSNP11.
