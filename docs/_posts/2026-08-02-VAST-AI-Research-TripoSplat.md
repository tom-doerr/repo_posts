# [VAST-AI-Research/TripoSplat](https://github.com/VAST-AI-Research/TripoSplat)

Converts a single 2D image into high-quality and variable numbers of 3D Gaussians. TripoSplat supports arbitrary Gaussian counts and runs on near-zero dependencies.
