# [HAKORADev/VODER](https://github.com/HAKORADev/VODER)

VODER brings together eight voice processing modes including speech-to-text, voice conversion, and music generation into one interface. It supports multi-speaker dialogue scripting, voice cloning from text or reference clips, and translation via TranslateGemma 12B, running entirely on your machine without a subscription.
