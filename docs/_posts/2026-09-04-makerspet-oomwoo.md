# [makerspet/oomwoo](https://github.com/makerspet/oomwoo)

Build a fully local, open-source robot vacuum with OOMWOO, a DIY project combining 3D-printed hardware, Raspberry Pi, and 2D LiDAR. It performs autonomous navigation and mapping directly on-device using ROS2, maintaining privacy by avoiding cloud reliance while integrating natively with Home Assistant.
